TubeTone — YouTube to MP3 (Windows)
===================================

Just run TubeTone.exe — no Chrome extension needed.

SETUP
  1. Unzip this folder anywhere
  2. Double-click TubeTone.exe
  3. First run may download ffmpeg (~80 MB) once — wait until it says Ready

DOWNLOAD
  1. Paste a YouTube link (or several links, one per line)
  2. Choose bitrate (64 / 128 / 192 / 256 / 320)
  3. Choose save folder (default: Downloads\TubeTone)
  4. Click "Download MP3"

TIPS
  - Keep TubeTone.exe open while downloading
  - If Windows SmartScreen appears: More info → Run anyway
  - Log file: %LOCALAPPDATA%\TubeTone\launcher.log

Only download content you have the right to use.
