YTMP 1.3 — Windows media toolkit
================================

Install: run YTMP-Setup.exe (includes ffmpeg).

After open you should see four tabs at the top of the window:
  1. Download  — paste links (YouTube + many sites), MP3/M4A/WAV/FLAC/Opus/MP4
  2. Convert   — local file or whole folder to other formats
  3. Tools     — trim, compress, GIF, normalize, speed, volume, fade, mono,
                 mute, rotate, reverse, remux, split, merge, snapshot, info
  4. Library   — search history, open files

If you only see Download MP3 / Cancel / Clear with NO Convert / Tools / Library tabs,
you are running an old install. Uninstall, then reinstall this package.

License: activate with your YM- key from the website.
Default save folder: Downloads\YTMP
