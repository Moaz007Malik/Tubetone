YTMP will install:

  • App → C:\Program Files\YTMP
  • ffmpeg → C:\ffmpeg\bin
  • Environment variable FFMPEG_LOCATION
  • C:\ffmpeg\bin added to system PATH
  • Desktop shortcut (optional)
  • Production license API URL from config.defaults.json (bundled)

Requires online license activation.
No Python or Chrome extension is required.
Administrator permission is needed for Program Files and PATH.
